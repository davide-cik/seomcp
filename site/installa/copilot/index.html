seomcp in GitHub Copilot

Istruzioni per GitHub Copilot in VS Code e GitHub Copilot CLI. Ci vogliono due minuti, credenziali a parte.

Prima di iniziare

  • Node.js 22 o superiore (scarica) e git (scarica).
  • Le credenziali delle fonti che vuoi usare: Google Search Console e/o Bing Webmaster Tools. Sono entrambe facoltative.

Il pacchetto npm è in arrivo: per ora seomcp si installa direttamente da GitHub. Il primo avvio richiede qualche secondo in più, perché il codice viene compilato sul tuo computer.

GitHub Copilot in VS Code

In VS Code i server MCP sono disponibili nella chat di GitHub Copilot, in modalità Agent.

  1. Apri la configurazione

    Apri la palette dei comandi (Ctrl/Cmd+Shift+P) ed esegui MCP: Open User Configuration. Si apre il file mcp.json del tuo profilo.

  2. Aggiungi seomcp

    {
  "servers": {
    "seomcp": {
      "type": "stdio",
      "command": "npx",
      "args": ["-y", "github:davide-cik/seomcp"],
      "env": {
        "GOOGLE_APPLICATION_CREDENTIALS": "/percorso/service-account.json",
        "BING_WEBMASTER_API_KEY": "la-tua-chiave",
        "SEOMCP_GSC_SITE": "sc-domain:tuosito.it"
      }
    }
  }
}

    Sostituisci percorso, chiave e sito con i tuoi. Se usi una sola fonte, togli la variabile dell'altra.

    Attenzione: in VS Code la chiave principale è servers, non mcpServers.

  3. Verifica

    Esegui MCP: List Servers dalla palette e avvia seomcp. Poi apri la chat di Copilot in modalità Agent: i tool compaiono nell'elenco degli strumenti.

GitHub Copilot CLI

Copilot CLI legge i server MCP dal proprio file di configurazione nella tua cartella utente.

  1. Apri la configurazione

    Apri (o crea) il file ~/.copilot/mcp-config.json.

  2. Aggiungi seomcp

    {
  "mcpServers": {
    "seomcp": {
      "type": "local",
      "command": "npx",
      "args": ["-y", "github:davide-cik/seomcp"],
      "env": {
        "GOOGLE_APPLICATION_CREDENTIALS": "/percorso/service-account.json",
        "BING_WEBMASTER_API_KEY": "la-tua-chiave",
        "SEOMCP_GSC_SITE": "sc-domain:tuosito.it"
      },
      "tools": ["*"]
    }
  }
}

    Sostituisci percorso, chiave e sito con i tuoi. Se usi una sola fonte, togli la variabile dell'altra.

    "type": "local" indica un server avviato sul tuo computer. "tools": ["*"] abilita tutti i tool.

  3. Verifica

    Riavvia Copilot CLI: i tool di seomcp saranno disponibili nella sessione.

Prova con una domanda

  • Quali query sono in posizione 4-20 negli ultimi 90 giorni?
  • Confronta questo mese con lo stesso periodo dell'anno scorso.

Se qualcosa non va

Questo comando controlla la configurazione e prova ogni fonte, dicendoti esattamente cosa manca:

npx -y github:davide-cik/seomcp doctor
  • Le variabili d'ambiente vanno impostate nella configurazione dell'assistente, non nel terminale: è l'assistente ad avviare seomcp.
  • Ancora bloccato? Apri una segnalazione, allegando l'output di doctor senza chiavi.
