Installa seomcp

Scegli il tuo assistente.

Versioni web non supportate. claude.ai, chatgpt.com, l'app Gemini, Microsoft 365 Copilot e Mistral Vibe sul web accettano solo server MCP remoti. seomcp gira in locale per non far uscire le tue credenziali dal computer, quindi servono le app desktop o la riga di comando.

Prima di iniziare

  • Node.js 22 o superiore (scarica) e git (scarica).
  • Le credenziali delle fonti che vuoi usare: Search Console, Google Analytics 4, Core Web Vitals e Bing Webmaster Tools, con i link diretti nella pagina Credenziali. Sono tutte facoltative: GEO, schema.org e controlli tecnici funzionano senza.

La via più rapida è la configurazione guidata: fa le domande una alla volta, prova le credenziali e scrive la configurazione dell'assistente al posto tuo.

npx -y github:davide-cik/seomcp setup

Il pacchetto npm è in arrivo: per ora seomcp si installa direttamente da GitHub. Il primo avvio richiede qualche secondo in più, perché il codice viene compilato sul tuo computer.
