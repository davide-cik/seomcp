seomcp in Claude

Istruzioni per Claude Code e Claude Desktop. Ci vogliono due minuti, credenziali a parte.

Prima di iniziare

  • Node.js 22 o superiore (scarica) e git (scarica).
  • Le credenziali delle fonti che vuoi usare: Search Console, Google Analytics 4, Core Web Vitals e Bing Webmaster Tools, con i link diretti nella pagina Credenziali. Sono tutte facoltative: GEO, schema.org e controlli tecnici funzionano senza.

Il pacchetto npm è in arrivo: per ora seomcp si installa direttamente da GitHub. Il primo avvio richiede qualche secondo in più, perché il codice viene compilato sul tuo computer.

Claude Code

Claude Code aggiunge i server MCP con un solo comando da terminale.

  1. Apri la configurazione

    Apri un terminale. Non serve modificare file: il comando claude mcp add scrive la configurazione al posto tuo.

  2. Aggiungi seomcp

    claude mcp add seomcp -s user \
  -e GOOGLE_APPLICATION_CREDENTIALS=/percorso/service-account.json \
  -e BING_WEBMASTER_API_KEY=la-tua-chiave \
  -e SEOMCP_GSC_SITE=sc-domain:tuosito.it \
  -e SEOMCP_GA_PROPERTY=123456789 \
  -e SEOMCP_GOOGLE_API_KEY=la-tua-api-key \
  -- npx -y github:davide-cik/seomcp

    Sostituisci percorso, chiave, sito e proprietà con i tuoi. Togli le variabili delle fonti che non usi.

    L'opzione -s user rende seomcp disponibile in tutti i tuoi progetti, non solo in quello corrente.

  3. Verifica

    Avvia claude e digita /mcp: seomcp deve risultare connesso.

Claude Desktop

Claude Desktop, per macOS e Windows, legge i server MCP da un file di configurazione JSON.

  1. Apri la configurazione

    Apri Impostazioni → Sviluppatore → Modifica configurazione. Si apre il file claude_desktop_config.json:

    • macOS: ~/Library/Application Support/Claude/claude_desktop_config.json
    • Windows: %APPDATA%\Claude\claude_desktop_config.json

  2. Aggiungi seomcp

    {
  "mcpServers": {
    "seomcp": {
      "command": "npx",
      "args": ["-y", "github:davide-cik/seomcp"],
      "env": {
        "GOOGLE_APPLICATION_CREDENTIALS": "/percorso/service-account.json",
        "BING_WEBMASTER_API_KEY": "la-tua-chiave",
        "SEOMCP_GSC_SITE": "sc-domain:tuosito.it",
        "SEOMCP_GA_PROPERTY": "123456789",
        "SEOMCP_GOOGLE_API_KEY": "la-tua-api-key"
      }
    }
  }
}

    Sostituisci percorso, chiave, sito e proprietà con i tuoi. Togli le variabili delle fonti che non usi.

    Se il file contiene già altri server, aggiungi solo il blocco "seomcp" dentro mcpServers.

  3. Verifica

    Chiudi Claude Desktop del tutto (non basta chiudere la finestra) e riaprilo. Nel menu degli strumenti della chat deve comparire seomcp.

Prova con una domanda

  • Quali query sono in posizione 4-20 negli ultimi 90 giorni?
  • Confronta questo mese con lo stesso periodo dell'anno scorso.

Se qualcosa non va

Questo comando controlla la configurazione e prova ogni fonte, dicendoti esattamente cosa manca:

npx -y github:davide-cik/seomcp doctor
  • macOS con nvm, fnm o Volta: le app desktop non vedono il PATH del terminale. Se il server non parte, in command metti il percorso completo di npx, che ottieni con which npx.
  • Windows: se il server non parte, sostituisci "command": "npx" con "command": "cmd" e metti "/c", "npx" all'inizio di args.
  • Le variabili d'ambiente vanno impostate nella configurazione dell'assistente, non nel terminale: è l'assistente ad avviare seomcp.
  • Ancora bloccato? Apri una segnalazione, allegando l'output di doctor senza chiavi.
