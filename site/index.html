Un server MCP che permette al tuo assistente AI di leggere i dati dei tuoi siti. Fai domande in italiano e ottieni analisi sui dati veri. Le credenziali restano sul tuo computer.

Perché fidarsi

Affidare le credenziali di Search Console a uno strumento è una decisione seria. Per questo seomcp è fatto per essere verificato, non solo usato.

Sola lettura

Chiede a Google solo gli scope webmasters.readonly e analytics.readonly: non può modificare nulla nelle tue proprietà.

Credenziali in locale

Gira sul tuo computer. Nessun server intermedio, nessun gateway di terzi: i dati vanno da Google e Bing direttamente a te.

Nessuna telemetria

Non raccoglie statistiche d'uso e non contatta altri server. Nemmeno questa pagina usa cookie o tracker.

Solo librerie ufficiali

SDK MCP, i client ufficiali @googleapis per Search Console, Analytics, PageSpeed e CrUX, e google-auth-library. Bing è una semplice chiamata REST.

Codice leggibile

Circa 4.800 righe di TypeScript, con test e CI. Si legge in un'ora, prima di installarlo.

Rispetta le regole

Non usa la Google Indexing API, che Google riserva alle offerte di lavoro e alle dirette video.

Cosa puoi chiedere

Il server restituisce dati puliti. Le analisi le fa l'assistente, ragionando su quei dati.

  • Confronta questo mese con lo stesso periodo dell'anno scorso e segnala i cali di clic sopra il 30%.
  • Quali pagine ricevono molti clic da Google ma convertono poco?
  • Perché ChatGPT cita il mio concorrente e non me? Confronta le due pagine.
  • Questa pagina è indicizzata? Quale canonical ha scelto Google?
  • Su Bing come va la query "corso SEO" rispetto a Google?
  • Il sito supera i Core Web Vitals su mobile? Com'è cambiato l'LCP nelle ultime settimane?
  • Le sitemap hanno errori? Quando le ha scaricate Google l'ultima volta?

Installa in 3 passi

Configura solo le fonti che usi: Google e Bing sono entrambe facoltative.

Provalo subito da GitHub. Il pacchetto npm @contentisking/seomcp è in arrivo. Nel frattempo i comandi qui sotto installano seomcp direttamente dal repository. Il primo avvio richiede qualche secondo in più, perché il codice viene compilato sul tuo computer. Serve anche git installato.

  1. Prepara le credenziali

    Solo per le fonti che usi: GEO, schema.org e controlli tecnici funzionano senza. Per Google scegli tra service account e OAuth, per Bing basta una API key. Ogni passaggio ha il link diretto alla pagina giusta, e alla fine la configurazione si compila da sola.

    Prepara le credenziali →

  2. Collegalo al tuo assistente

    Versioni web non supportate. claude.ai, chatgpt.com, l'app Gemini, Microsoft 365 Copilot e Mistral Vibe sul web accettano solo server MCP remoti. seomcp gira in locale per non far uscire le tue credenziali dal computer, quindi servono le app desktop o la riga di comando.

  3. Controlla che funzioni

    npx -y github:davide-cik/seomcp doctor

    Prova ogni fonte e ti dice esattamente cosa manca. Per esempio: «aggiungi seomcp@progetto.iam.gserviceaccount.com come utente della proprietà».
