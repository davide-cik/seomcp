# Sicurezza

Se trovi una vulnerabilità **non aprire una issue pubblica**. Usa la funzione [Report a vulnerability](https://github.com/davide-cik/seomcp/security/advisories/new) di GitHub. Rispondiamo appena possibile; il progetto è mantenuto nel tempo libero.

Particolarmente importanti:

- esposizione di credenziali (token Google, API key Bing) in log, errori o file;
- permessi dei file di token e configurazione;
- dipendenze compromesse.
